## Announcements

<Icon icon="rocket-launch" iconType="regular" /> We're excited to announce the release of Nemesis v2.0! <Icon icon="rocket-launch" iconType="regular" />

Nemesis v2.0 focuses on the features that support and streamline real-world use cases of red team operators, including:

- Automated file enrichment and analysis
- Centralized file triage in a browser interface
- Structured data storage and search

<Tip>Learn more about our new philosophy for Nemesis v2.0 in our [blog post](https://specterops.io/blog/2025/08/05/nemesis-2-0/).</Tip>

## Summary

Major changes in Nemesis v2.0 include:

- **Simplified architecture** - Reduced complexity and improved flexibility by replacing Kubernetes with Docker Compose, removing Elasticsearch (consolidating all data storage in PostgreSQL), and dropping complex protobuf schemas.
- **Dapr integration** - Integrated with [Dapr (Distributed Application Runtime)](https://specterops.github.io/Nemesis/dapr/) for workflow management, pub/sub messaging, and service invocation.
- **New user interface (UI)** - Rebuilt the UI to focus on operator workflow and improve the file and findings triage user experience.

### New features

This release includes the following new features:

- **Enhanced file viewers** - View and interact with [files](https://specterops.github.io/Nemesis/usage_guide/#files) in multiple ways directly in the browser (for example, ZIP exploration, hex viewers, and syntax-highlighted code display).
- **Keyboard-driven triage** - Press `t` in any file or findings list to enter [triage mode](https://specterops.github.io/Nemesis/usage_guide/#file-triage-mode), quickly mark items as viewed/triaged, and navigate to more details.
- **Dynamic Yara rules** - Add, edit, and manage [Yara rules](https://specterops.github.io/Nemesis/yara/) directly through the web interface.
- **File tagging and filtering** - Organize and filter files based on your workflow needs with a [custom tagging](https://specterops.github.io/Nemesis/usage_guide/#file-tags) system.
- **Collaborative triage** - Filter file views by [operator view and view state](https://specterops.github.io/Nemesis/usage_guide/#files) to streamline multi-player mass file triage.
- **Smart alerting** - Integrate with messaging services, like Slack and Apprise, to enable real-time [alert notifications](https://specterops.github.io/Nemesis/usage_guide/#alerting) for high-priority findings.
- **Container build pipelines** - Build and publish Nemesis containers using our [GitHub Actions workflows](https://github.com/SpecterOps/Nemesis/tree/main/.github/workflows) for both x86 and ARM architectures.
- **Enrichment modules** - Create new [enrichment modules](https://specterops.github.io/Nemesis/file_enrichment_modules/) faster using the redesigned module system.
